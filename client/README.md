# Portal de Apoio ao Usuário — Arka Tecnologia

Prévia funcional baseada na especificação fornecida.

## Requisitos
- Node.js 18+ (recomendado Node 20+)

## Executar
Abra um terminal nesta pasta e rode:

```bash
npm install
npm run dev
```

Depois acesse o endereço mostrado pelo Vite, normalmente:
http://localhost:5173/

## O que está funcionando nesta prévia
- Busca dinâmica por título, descrição, categoria e palavras-chave
- Filtros por categoria
- 20+ artigos demonstrativos
- Modal de leitura de artigo
- FAQ com accordion
- Checklist antes de abrir chamado
- Formulário visual de chamado (mock; não envia para sistema externo)
- Menu responsivo
- Botão flutuante de suporte
- Animação de partículas com CSS keyframes
- Visual dark/premium e responsivo

A prévia utiliza a logo oficial fornecida na conversa, armazenada em `public/arka-logo.png`.
